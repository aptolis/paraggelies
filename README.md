# Παραγγελίες App

Εφαρμογή παραγγελιοληψίας για κινητό (PWA).

## Χαρακτηριστικά
- Ιστορικό παραγγελιών ανά πελάτη
- Κατάλογος 350+ προϊόντων ανά προμηθευτή
- Ζώνες: ΚΤΨ / Συντήρηση / Αποθήκη
- Live αναζήτηση με αργκό
- Φωνητική εισαγωγή
- Καραντίνα νέων προϊόντων
- Backup / Restore δεδομένων
- Δρομολόγια ανά περιοχή

## Εγκατάσταση (GitHub Pages)
1. Fork ή upload σε GitHub repository
2. Settings → Pages → Branch: main
3. Άνοιξε το URL στο κινητό
4. "Προσθήκη στην αρχική οθόνη"

## Τεχνολογίες
- Vanilla HTML/CSS/JS
- localStorage για αποθήκευση
- PWA (Progressive Web App)
